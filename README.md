# 📱 Jib o Bi3

Jib o Bi3 is a mobile marketplace application that enables users to buy and sell second-hand products quickly and securely. The application provides an intuitive interface for posting listings, searching products, communicating with sellers, and managing transactions.

## ✨ Features

- User Authentication (JWT)
- Browse product listings
- Advanced search and filtering
- Category management
- Favorite products
- Real-time chat between buyers and sellers
- Product reviews and ratings
- Push notifications
- User profile management
- AI-powered chatbot assistant
- Fraud detection system for suspicious listings
- Image upload
- Location support

## 🛠️ Technologies

- React Native (Expo)
- JavaScript
- Node.js
- Express.js
- JWT Authentication
- REST API
- SQLite (Offline Storage)
- Expo Notifications
- Gemini API (AI Chatbot)

## 🚀 Installation

Clone the repository

```bash
git clone [https://github.com/yourusername/jib-o-bi3-mobile](https://github.com/ushagour/JibOBi3/).git
```

Install dependencies

```bash
npm install
```

Start Expo

```bash
npx expo start
```
